# StrokeLab

[English](README.md) | **Русский**

**Анализ центральных осей штрихов и предсказание тонкого начертания по векторным контурам.**

StrokeLab — экспериментальный инструмент для шрифтового дизайна. Программа анализирует векторные контуры глифов, определяет предполагаемые центральные оси штрихов и использует их для построения предсказания более тонкого начертания.

## Назначение программы

StrokeLab работает с векторными контурами глифов, хранящимися в файлах шрифтов. Программа не растеризует буквы и не использует диаграмму Вороного как основу анализа.

Инструмент предназначен для исследования структуры штрихов, поиска вероятных центральных осей и получения отправной точки для создания более тонкого мастера. Результат является алгоритмическим предсказанием, а не гарантированно готовым контуром для выпуска шрифта. Перед использованием в готовом шрифте необходимо проверить и при необходимости исправить полученные контуры.

### 1. Анализ контуров

Контуры глифа раскладываются на прямые сегменты и кривые. Для них вычисляются геометрические характеристики: касательные, поворот, длина и нормали, направленные внутрь материала. Узлы классифицируются по локальной геометрии: выпуклые углы, вогнутые углы, гладкие узлы и точки перегиба.

### 2. Поиск штрихов и их осей

Штрих рассматривается как область между двумя сторонами. Кандидатные пары рёбер проверяются с помощью лучей по внутренним нормалям, взаимной ориентации нормалей и теста пустого круга, построенного на отрезке между точками-кандидатами. В текущей логике прямые рёбра сопоставляются с прямыми, а кривые — с кривыми.

Середины между принятыми парами точек формируют выборку центральной оси. Расстояние между сторонами даёт локальную оценку толщины штриха. Фрагментированные участки оси могут объединяться, а переходы между соседними участками сглаживаются.

### 3. Общие оси и предсказание соединений

Программа различает настоящий торец штриха и место соединения с другим штрихом. Соединение оценивается с опорой на исходный контур, в том числе на близлежащие вогнутые углы. Текущая модель учитывает несколько типов соединений:

- **T** — конец одного штриха упирается в ось другого;
- **L** — угловое соединение двух штрихов;
- **Y** — соединение трёх концов в одном узле;
- **X** — пересечение двух осей;
- **G1** — плавное продолжение, например переход стойки в арку или участок S-образной формы.

Продление осей ограничивается материалом глифа. Если предполагаемая центральная линия выходит из материала, в соответствующих местах она может идти по середине доступного прохода. Свободные концы достраиваются до видимого торца, а не соединяются с посторонним штрихом.

### 4. Предсказание тонкого контура

По осям и измеренному профилю толщины строятся ленты штрихов. При исходной толщине они могут сравниваться с исходным контуром; программа показывает сведения о совпадении и лишней площади. Уменьшение толщины позволяет получить предсказание более тонкого начертания.

Для глифов только с прямыми рёбрами и для глифов с кривыми используются разные наборы параметров. Набор выбирается автоматически по определённому классу глифа.

### 5. Торцы, точки и экспорт

- Ленты штрихов обрезаются по исходной линии торца. Это помогает сохранять косые и угловые срезы и подрезать выступающие углы.
- Точки и отдельные знаки, например точки над **i** и **j**, а также двоеточие, обрабатываются отдельно и могут уменьшаться относительно своего центра.
- Соединение T по умолчанию строится прямым; круговой вход в стойку применяется только тогда, когда конец почти параллелен ей.
- Исходные осевые пути можно экспортировать как открытые линии без заливки в рабочие процессы UFO, Designspace и Glyphs. Для некоторых функций экспорта в Glyphs 3 требуются дополнительные библиотеки из списка необязательных зависимостей.

## Установка

### Требования

- Windows 10 или новее. Другие платформы могут работать, но текущая версия прежде всего ориентирована на Windows.
- Python **3.11 или новее** для актуального набора незакреплённых по версиям зависимостей. Современные версии FontTools требуют Python 3.11 или новее.
- Файл шрифта OpenType или TrueType, который поддерживается FontTools.

### 1. Создание виртуального окружения

Откройте PowerShell в папке с `Strokelab.py`:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Если PowerShell запрещает активацию окружения, можно вызывать Python напрямую: `.venv\Scripts\python.exe`.

### 2. Установка обязательных библиотек

```powershell
python -m pip install -r requirements.txt
```

### 3. Установка дополнительных возможностей (необязательно)

```powershell
python -m pip install -r requirements-optional.txt
```

Дополнительные пакеты обеспечивают удаление наложений контуров и расширенные сценарии экспорта. Без них программа должна запускаться, но соответствующие дополнительные функции могут быть недоступны.

## Запуск

Запуск без предварительно указанного шрифта:

```powershell
python Strokelab.py
```

Запуск с указанием файла шрифта:

```powershell
python Strokelab.py "C:\Fonts\Example-Bold.otf"
```

Файл шрифта также можно перетащить в окно программы.

## Управление на холсте

| Действие | Управление |
|---|---|
| Масштабирование вокруг курсора | Колесо мыши |
| Перемещение холста | Перетаскивание левой, средней или правой кнопкой мыши |

| Вписать глиф в окно | Двойной щелчок |

Управление и названия элементов интерфейса могут меняться по мере развития программы.
